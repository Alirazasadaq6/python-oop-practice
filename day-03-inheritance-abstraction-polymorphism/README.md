**Day 03 - Inheritance, Abstraction and Polymorphism**



Topics:

**Inheritance**

* Single Inheritance
* Multilevel Inheritance
* Multiple Inheritance
* Hierarchical Inheritance
* Hybrid Inheritance



**Abstraction**

* Abstract Classes
* Abstract Methods
* ABC Module



**OOP Concepts**

* Method Overriding
* Polymorphism



Features:

**Inheritance**

* Create parent and child classes
* Inherit attributes and methods
* Use parent constructors
* Work with different inheritance types



**Abstraction**

* Create abstract classes using ABC
* Create abstract methods
* Enforce method implementation in child classes
* Prevent object creation of abstract classes



**Method Overriding**

* Replace parent class methods in child classes
* Customize behavior of inherited methods



**Polymorphism**

* Use the same method name in different classes
* Execute different behaviors through a common interface
* Work with multiple objects using a single loop
